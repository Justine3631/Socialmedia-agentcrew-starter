# 声音素材准备

分享版不附带音频文件；音效须由使用者自行取得授权后下载或原创录制。上游 Pixabay 音频不能作为独立素材包重新分发。

1. 按 `media-editor/SKILL.md` 的音乐与音效检索流程准备声音。
2. 将来源、作者、许可证、下载日期与 SHA-256 写入本期 `05audio/source-manifest.md`。
3. 使用 `sound-event-map.template.json` 记录可见动作、触发帧与尾音。
4. 对齐动作后在真实成片中试听；未取得声音时明确标缺口，不声称已经铺音。

响度与混音判断见 `shared/skill-bases/剪辑师/音频制作.领域.md`。
