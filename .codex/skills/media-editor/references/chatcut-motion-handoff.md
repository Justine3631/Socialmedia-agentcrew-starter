# ChatCut 动效接入规范

当前规范只定义交接；没有真实分镜、素材和可编辑 ChatCut 项目时不得创建正片时间线。

## 前置输入

- 已锁定的口播粗剪时长。
- `03outputs/分镜.md` 中明确需要设计动效的镜头。
- 对应口播、录屏或截图素材。
- 10–15 秒视觉与运动样片方向已进入制作预览卡；预览保留素材已有口播，不带配乐/音效，声音在完整候选验收。

## 交接内容

每个动效镜头提供：

- 镜头 ID、开始时间、持续时间。
- settled frame 截图。
- HyperFrames 源码或 ChatCut Motion Graphic JSX。
- 透明背景要求；需要完整画面时明确标为 full-frame beat。
- 屏幕安全区、字幕避让区和人物避让区。
- 声音事件表：动作、触发帧、文件、响度、声像和尾音。

## ChatCut 执行

1. 用 `read_project` 确认项目、fps、目标轨道和真实素材。
2. 先检查目标帧，再决定动效 form、box 和 placement。
3. 每镜只选一种交接方式：默认将已确认的 HyperFrames 透明 MOV/WebM 或完整画面视频作为媒体导入，保留源码供外部修改；仅当用户明确需要在 ChatCut 内编辑图文或现有镜头已采用原生动效时，使用 `create_motion_graphic_from_code` 建立 JSX。工具及格式支持须在当前会话核验，不为接入强制重做另一份实现。媒体可在时间线上剪切，不等于其内部元素可编辑。
4. 使用当前可用的时间线编辑能力放置明确矩形、开始时间和持续时间；原生 JSX 可使用 `edit_item`。透明媒体先验证 alpha 与一段真实背景上的合成，格式不支持时记录缺口。
5. 音效作为独立音频 item 导入，保持可单独替换。
6. 用 `view_timeline_frames` 检查 settled frame 和过渡帧；只读项目元数据不能替代视觉证明。

## 降级

- ChatCut 后端不可用：保留 HyperFrames 透明 MOV/WebM 与声音事件表，写入剪辑说明书。
- 真实素材未锁定：只做技术样片，不在时间线上占位。
- 声音不合格：保留已确认画面，只替换失败的声音层。
