# 目标影片八层拆解

用于把参考视频或参考帧转译成原创、可制作的剪辑与动效规格。只学运动、空间、材质、声音和信息层级语法；不复制品牌资产、Logo、具体构图、原文案、原音乐或原音效。

## 证据边界

- 完整视频：可判断画面、时间、运动、剪辑和声音，但仍区分观察事实与制作推断。
- 静音视频：不得声称已分析声音；声音只写待验证建议。
- 单张截图：只能可靠判断主体、构图、层级、色彩、光影、字体倾向和材质；不得从单帧臆测真实运动路线、缓动、转场或音效。
- 看不清、听不清或缺帧时写 `unknown`，不靠 `cinematic`、`8K`、`masterpiece` 等标签补空白。

## 八层拆解

按镜头或语义段填写，不把整片混成一段提示词。

1. **语义目标**：这一镜要让观众理解、感受或确认什么；只写一个主目标。
2. **主体与状态**：主运动主体是谁；写清起点、过程、终点，以及次级元素依赖关系。
3. **布局与层级**：视觉锚点、主次关系、阅读顺序、前中后景、字幕和平台安全区。
4. **运动时序**：动作起止时间、预备、加速、减速、轻微越位、落稳和结果保持；能数帧时优先写帧。
5. **转场连续性**：切前切后由方向、位置、尺度、亮度、材质、标签或声音尾音中的哪些锚点接力。
6. **材质与光色**：UI、纸张、真人、镜头等各自运动身份；记录字体倾向、纹理、阴影、色温和对比，不用风格词代替可见特征。
7. **声音事件**：中心床、材质声、交互声、宽瞬态、结果音和留白；标出峰值对应的接触、锁定、完成或验证帧。
8. **输出规格**：时长、比例、分辨率、帧率、字幕安全区、透明通道和交付后端。

## 从拆解到制作

1. 先完成观察事实和未验证项，再提出制作推断。
2. 把参考片的品牌内容替换为当前项目语义、素材和账号视觉。
3. 每镜只保留一个主动作；次级元素错峰或弱响应。
4. 用可测参数描述动作，不写“高级、丝滑、电影感”代替规格。
5. 声音峰值绑定可见结果；无声音证据时先做候选，不声称复刻。
6. 先做代表镜头或 10–15 秒视觉与运动样片，保留已有口播、不带配乐/音效，检查静音可辨和正常速度可读。完整候选铺声音后，再闭眼听声音与声画合看，不对无配乐/音效预览提出声音层数要求。

## 合格与不合格

不合格：

> 蓝色卡片飞入，电影感，8K，masterpiece，丝滑音效。

合格：

> 卡片在 0–5 帧从右侧快速进入并由 96% 放大到 100%；6–10 帧减速落位，最多 2% 越位；标题延迟 4 帧出现；接触中心锚点时触发短 click，结果保持至少 18 帧。具体配色、文案和声音素材使用本项目原创或已授权资源。
