# 平台播放安全区

下列坐标是布局起点，须按实际发布平台界面复核。分享版不附带原用户截图；编辑器应按坐标绘制检查叠层。黑色区域为主要播放安全区；彩色区域为平台界面或裁切风险区。背景和纯装饰可出界，钩子、字幕、人物面部、演示焦点、按钮和关键信息不得出界。人物的头发边缘、肩膀、手臂和身体可以进入风险区或被平台界面遮挡，但不得影响动作含义、主体识别或人物面部。

## 非基准分辨率

同一比例按画布尺寸等比换算：

```text
x' = round(x × 实际宽度 ÷ 基准宽度)
y' = round(y × 实际高度 ÷ 基准高度)
```

## 检查步骤

1. 开始排版前确认画布比例，读取对应数据。
2. 关键帧预览叠加按坐标绘制的检查层，检查标题、字幕、人物面部和操作焦点。
3. 调整完成后关闭叠图再交付干净关键帧。
4. 10秒样片与最终导出各抽查一次实际成片，不用网页布局代替成片检查。
