# 声音资源生产与交接

仅在本期需要文字配音、声音克隆或替换合成旁白时加载。岗位负责制作决策与验收；模型调用遵循当前可用专业 Skill、官方接口或已验证本地实现，不复制完整服务教程。

## 输入和职责

以 `02script/script.md` 为内容真相，结合分镜的稿段/镜头 ID、表达要求和账号 `voice-profile.md`。读法替换不得改变事实、数字含义或承诺；需要内容改动时交回编剧。导演决定人物出镜位置和表演，资产制片交付旁白，剪辑师安排时间线与混音。声音生成失败退回资产制片；已验收旁白的混音或时间线问题由剪辑师处理。

## 制作步骤

1. **检查可用输入。** 复用已获授权的音色或本人参考录音，核对路径、可读性、时长和已有试听。生成授权沿用当前请求范围，不因新一期开稿擅自换人、上传到新服务或触发付费调用。工具不可用就记缺口，不将安装 Skill 视为服务可用。
2. **分开显示和朗读。** 保留正常字幕文字，另准备 `05audio/narration-vNN.md`，按稿段/镜头 ID 写原文、朗读文本和必要读音。例如显示 `3.5%`，朗读“百分之三点五”；缩写和术语按语境固定。不要把修发音的谐音写进正式字幕。
3. **选择实际支持的控制。** 明确模型、参考音色和参数版本。普通标点、SSML、模型音频标签分别核对，不能跨模型照搬；Base 克隆模型不能自动套用其他模型的情绪接口。先修错字漏字和读法，再处理停顿、重音和节奏。
4. **生成并留版本。** 新音色或新后端先做低成本短段；已验收配置按自然语义分段，避免每句重置导致语气断裂。长稿按实际语速留足生成上限，若时长接近 token 上限或句尾不完整，检查截断，不把固定短句参数当作长稿预设。失败后保留错误，定位原因再作一次有依据的重试；连续失败、付费/额度错误或明显超时则报告，不循环提交。保留旧版，不覆盖已锁定音轨。
5. **分层验收。** 文件能解码、非空、有声音和无削波只是技术检查。逐句对照定稿检查漏字、重复、数字、术语、句尾完整；另听音色一致、语气、停顿、噪声和音量。近静音或仅有文件写出不能通过。没有听到或无法转写核对时，逐字完整度与自然度标为待验收，交老板或具备实际音频审听能力的工具核对，不能凭波形宣称通过。
6. **交接。** 音频命名 `05audio/narration-vNN.wav`，首次需要时创建 `05audio/voice-QA.md`，记录稿件版本/哈希、模型与参考来源、授权依据、参数、生成耗时、输出时长、逐句问题时间点、验收人/方式、结论和当前选用版本。在原有 `04media/asset-manifest.md` 中登记音频相对路径与稿段/镜头关系；多个稿段可分行，无需另建资产数据库。字幕取显示文本，时间从实际音频得到。

## 诊断与试验

- 不像本人：先查参考录音和音色/模型；字错：先查朗读文本、词表或兼容发音控制；字都对但机械：先查分句和表达控制；文件近静音：查输出和生成条件，不能只放大音量掩盖失败。
- A/B 试验固定音色、模型和其他条件，A 为原稿，B 只修朗读文本/分句。只有模型存在另一项已确认支持且未在 B 改过的控制时才加 C；否则省略 C。随机生成有波动，一次改善只能算样本证据。
- 旁白修改后，在 manifest 和 voice-QA 写明受影响稿段/镜头，通知剪辑师检查字幕时间、人物口型、操作画面节点和总时长。原始截图等无关资产可沿用。
- 后期可剪尾部空白、调音量，但保留原始输出并标注处理版；不可剪掉未完成句尾后把漏字隐藏为“清理静音”。
