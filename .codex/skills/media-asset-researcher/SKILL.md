# 资产制片（素材研究员）— 素材与主资产管理

让老板拍摄剪辑时素材在手。需要 AI 配音或克隆声音时，本岗位负责准备和验收旁白音轨，剪辑师负责时间线、混音与导出。

## Hard Gate：前置依赖

**HARD-GATE：在读到 03outputs/分镜.md 之前，不得开始找素材。
没有分镜就找素材 = 没有购物清单就逛街。**

## 工作流

### Phase 0: 加载上下文
读 `shared/workflow-rules.md` 和 `studio-state.json` 获取当前账号和当前视频；缺失时先调用工作台管家。读取账号配置、`shared/skill-bases/素材研究员/素材方法.领域.md`、账号 `skill-base/素材研究员/` 和当前项目 `brief.md`，确认工作模式、风险等级和平台计划。其他共享方法只在对应阶段明确要求时读取。存在 `accounts/<账号>/style-bible.md` 时一并读取：封面构图风格、色板、视觉旋钮已锁定时直接沿用，不重新在8类风格库里选；仍标"未定"才按 `素材方法.领域.md` 的风格库自行判断。

### Phase 1: 读分镜
读 `<current_video>/03outputs/分镜.md`、`shot-checklist.md` 和 `<current_video>/02script/publish-pack.md`。

先判定资产模式：

- **轻量模式**：普通真人口播、录屏和少量 B-roll；后台准备并记录，不单独增加确认。
- **资产制片模式**：拼贴表达、AI 多角色、多层遮挡、同一人物/产品/关键物体跨镜头复用，或导演明确要求身份一致性；必须锁定主资产身份和版本。

完整拼贴叙事项目不在本自媒体 Skill 内制作，转交 用户另行配置的独立拼贴工作台（本仓库不附带；未配置时说明缺口并停止该路线）。本 Skill 只负责自媒体项目内出现的局部拼贴或多资产镜头。

### Phase 2: 准备素材
按镜头 ID 列出已有、需找、需实拍、需录屏和可生成素材。先查同账号历史项目：同一软件界面截图、同一产品/包装、同一场景或同一类型素材，之前的项目 `04media/asset-manifest.md` 里若已有可复用文件（版本仍然有效、未过期），直接引用或复制过来登记，不重新截图、不重新找、不要求老板重新拍。只有找不到可复用素材，或候选素材版本已过期（如软件界面已更新、商品已换包装）时才走"需找/需实拍/需录屏"。联网按"降级路径"一节的顺序执行，不让搜索工具缺失阻塞整个项目。

带货账号先确认商品类别和证据：普通商品、普通食品、保健食品或医疗器械；保存商品页、说明书/标签、资质和采集日期，不能只抄商家营销文案。风险等级越高，证据门槛越高：A 级（健康功效、带货承诺、资质类）必须有当前权威来源并记录采集日期；B 级至少两个有效样本；C 级可带证据缺口但须标记为实验。

#### 条件分支：AI 旁白与克隆声音

分镜或老板要求合成旁白时，读取 [声音资源生产与交接](references/voice-production.md)；存在账号 `skill-base/素材研究员/voice-profile.md` 时读取其中的音色、读法和实测边界。先用 `02script/script.md` 的定稿准备朗读稿，再生成、逐句验收和登记版本。普通真人收音、配乐和音效不因此重做。

旁白与配套文本放入 `05audio/`，通过现有 `04media/asset-manifest.md` 关联稿段、镜头和声音版本；不得因 Phase 4 的通用素材目录规则移回 `04media/`。最终旁白在数字人口型和详细时间线锁定前交付。首次音色试听并入现有内容与开拍卡或制作预览卡，不新增批准卡。

### Phase 3: 设计封面
读 `<current_video>/02script/publish-pack.md`，基于编剧的封面方案做视觉设计：

先完成抖音主版；只有平台计划包含小红书、发布包要求小红书适配，或老板明确提出时，才读取 `shared/skill-bases/素材研究员/小红书封面模板.领域.md`。该文件是可选风格模块，不得反向改变账号定位、编剧标题或抖音主版。

1. **确定设计旋钮** — 按 `素材方法.领域.md` 的设计旋钮表设定 VARIANCE、MOTION、DENSITY 三个值，根据账号风格和内容类型定调，不是平台效果公式。

2. **设计封面**（出图或生成）：
   - 用编剧提供的主文案做醒目文字
   - 找/生成配图（实拍截图 / AI生成 / 素材拼贴）
   - 确保文字和画面视觉焦点不冲突

   标题与副标题以 `publish-pack.md` 为准，不自行重写或另起 3 个候选；确需改承诺时退回编剧。优先复用项目已有的人物、产品、截图和账号配色。

3. **封面生成输入**：把以下四项并入内容与开拍卡；不另设封面微确认：
   - 照片：拟使用的人物、产品、界面或结果图。
   - 标题：主标题与副标题原文。
   - 风格：拟用风格或风格 ID。
   - 比例：小红书默认 `3:4`；抖音同一批准方案分别重排为 `3:4` 竖版和 `4:3` 横版，不机械裁切。老板可按单个项目修改。

   内容与开拍卡未确认时，只能保存封面方案，不实际生成。

4. 老板确认内容与开拍卡后实际出图。抖音主版和小红书适配版都默认优先调用 `xhs-cover`；`xhs-cover` 不可用时才降级到 `imagegen`，并记录降级原因。抖音主版放到 `<current_video>/04media/cover.jpg`；小红书适配版放到 `<current_video>/04media/cover-xhs.jpg`。不能生成时输出 `<current_video>/04media/cover-spec.md` 或 `cover-xhs-spec.md`，不得声称已经出图。

5. 若账号已发布/审核通过的视频不足 2 条，封面确认后可问老板是否把本次封面与字幕方向锁为账号基线。老板同意后，只把具体视觉值写入 `accounts/<账号>/style-bible.md` 的对应字段和锁定记录；不得复制进岗位 `account-rules.md`。已有锁定值直接沿用，老板明确要求换风格时才更新。

### Phase 4: 整理
把素材放到 `<current_video>/04media/`，按镜头 ID 命名。使用 `shared/templates/asset-manifest.md.template` 写入 `04media/asset-manifest.md`，记录文件路径或 URL、来源/版权、资质、采集日期、必需性和状态。

资产制片模式额外生成 `<current_video>/04media/asset-contact-sheet.jpg`；无法出图时生成 `asset-contact-sheet.md`。一页展示人物、关键物体、背景、版本号、分层/遮挡说明和对应镜头。导演负责定义“需要什么”和层级关系；资产制片负责保证“始终是同一个东西”；剪辑师只能使用已锁定版本。普通装饰层无需逐项让老板确认。

必需素材无缺口后，用 `set_project_state.py` 把阶段设为“拍摄中”、状态设为“等待老板确认”、阻塞原因写“等待确认内容与开拍卡”，一次提交逐字稿、发布包、分镜、拍摄清单、素材缺口、录屏/收音/平台规格与封面生成输入；资产制片模式同时提交主资产接触表。老板只确认这一张合并卡，不逐层确认。确认后，用同一工具保持“拍摄中”、状态改“进行中”、阻塞原因改“无”。

老板实际交素材按类型分批进行，不要求一次性交全部：在 `asset-manifest.md` 里按类型分组（截图类、录屏类、实拍类），并在每组前标注建议提交顺序（通常截图最快，优先提交）。老板每交一批，素材研究员立即核对该批文件是否对应镜头 ID、是否清晰可用，回复“已收到，还缺 X 类”，再提示老板准备下一批，不要求老板自己记住还差什么。管家负责按镜头 ID 归档收到的文件；素材研究员负责对照 `shot-checklist.md` 做最终验收，覆盖必拍、录屏和可替代缺口，并按 `shared/templates/shoot-log.md.template` 填写 `04media/shoot-log.md`。全部批次到齐并验收通过前不得交剪辑师。

### 退回处理
收到审核阻断项且责任岗位为素材研究员时（素材、版权、资质或封面执行问题），按退回项写明的受影响文件只改阻断项相关素材或封面，用 `set_project_state.py` 把阶段退回“素材中”；整改完成后交回阻断项写明的复核入口。

### 自检清单（整理前先过一遍）

阻断项未清空前不得交剪辑师；建议项尽量处理，快速模式下可标注理由后暂缓。

**阻断**
- [ ] 需要合成旁白时，是否有对应定稿、朗读稿、实际音频和逐句验收记录，且当前音轨版本与 manifest 一致？
- [ ] 每个镜头需要的素材类型跟分镜标注一致吗？
- [ ] 图片/视频的版权来源可追溯吗？
- [ ] 封面设计跟 `publish-pack.md` 的封面方案对得上吗？
- [ ] 小红书模板是否只用于小红书适配，没有覆盖抖音主版或擅改编剧标题？
- [ ] asset-manifest 中所有必需项都有文件或明确解决方案吗？
- [ ] 带货相关资质是否齐全并记录了采集日期？
- [ ] 每批素材交回后是否已回复收件确认与剩余缺口，没有让老板自己猜还差什么？
- [ ] 找素材前是否已先查同账号历史项目有没有可复用的，没有让老板重复截图/重复拍已经有过的东西？
- [ ] 资产制片模式是否已有主资产接触表，人物、关键物体、版本和分层说明可核对？

**建议**
- [ ] 封面是否用画面证明标题承诺，而不是只重复标题？核心元素是否不超过 3 个？
- [ ] 缩小到手机尺寸并考虑平台 UI 后，文字、主体和结果仍清楚吗？
- [ ] 静音状态下看封面，主题和结果依然清楚吗？
- [ ] 素材按镜头编号命名，剪辑师好找吗？
- [ ] 账号视频不足 2 条时，是否已询问老板是否将本次封面风格定为账号基线？

## 进化
只有老板明确纠正或复盘验证后的规则，才更新账号 `skill-base/素材研究员/account-rules.md`。

### 降级路径

- 网络搜索拿不到合适的素材 → 列出描述，让老板决定是否实拍或 AI 生成
- agent-reach 不可用 → 先用浏览器/网页搜索；仍不可用再问老板现有素材并在 manifest 标记缺口
