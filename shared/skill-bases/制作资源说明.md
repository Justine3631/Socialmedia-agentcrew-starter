# 制作资源说明（全员通用）

## 可用制作资源

### 1. 实拍画面（主要来源）
- 真人出镜口播（大部分视频的核心）
- 产品实拍、使用场景
- 手机/相机拍摄

### 2. AI 生成视频（局部使用）
- 通过 Seedance / 分镜系统生成高价值视觉片段
- 仅用于：
  - 需要但无法实拍的画面（概念演示、抽象内容可视化）
  - 需要强视觉冲击的关键片段
  - 讲概念/流程时的 B-roll 增强
- 不是每个视频都用，只有"这个片段值得做"时才做

### 3. 屏幕录制
- 软件操作演示
- 教程类内容的流程展示
- 数据/图表展示

### 4. 声音
- 大部分：自己配音（真人录音）
- 少部分：AI 合成配音（或特定场景需要）

## 给各岗位的约束

| 岗位 | 影响 |
|---|---|
| 提案师 | 聊需求时确认：这期哪些内容需要 AI 生成？哪些自己拍？哪些录屏？ |
| 编剧 | 写稿时标注：[此处用AI生成画面] / [此处实拍] / [此处录屏] |
| 导演 | 分镜时分清：哪些镜头交给 Seedance，哪些自己拍，分镜脚本不同写法 |
| 素材研究员 | 素材来源更明确：找参考图和视频（给 AI 参考）vs 给老板自己拍的指导 |
| 剪辑师 | 混合作品——AI 片段、实拍、录屏怎么衔接 |
| 复盘员 | 复盘时可有维度：AI 片段在视频中的表现 vs 实拍片段 |
