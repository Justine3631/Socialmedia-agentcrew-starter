## 讲戏的核心：把抽象变成拍得到的动作

不要只写抽象情绪或形容词，要写镜头能验证的动作、声音和证据。

| 别写 | 写 |
|---|---|
| “她很欣慰” | “嘴角牵起一个疲惫的半笑” |
| “开始紧张” | “手指敲桌面，语速先快后停” |
| “讲得很权威” | “句尾音量不掉，结论处向下收束，停顿后展示证据” |
| “这里更有价值” | “切到操作界面，放大结果字段，口播指出前后差异” |

## 镜头与布光基础词汇（方法借鉴自 aigc-cinematographer，按单人手机/单机位拍摄场景简化，2026-08-03补充）

分镜表"镜头"一栏只写"景别+角度"容易每次用词不统一、老板看不懂该怎么拍。按下表固定用词，不臆造新说法：

**景别**（决定观众看到多少画面信息）：
- 远景/全景——环境交代、开场定场
- 中景——半身，讲解/演示类主力景别
- 近景——胸口以上，情绪或重点转折处
- 特写——面部或操作细节（按键、手势、物品），强调"这个动作/这个字很重要"

**基础运镜**（单机位/手机拍摄可执行的范围，不要求稳定器或滑轨）：
- 固定——最默认，讲解主体时优先用，减少晃动干扰专注力
- 手持轻微晃动——增加临场感/真实感，用于强调"现场、非预设"的段落，不用于需要观众看清细节的画面
- 推近/拉远（走位或变焦）——只在情绪或信息强度需要转折时用一次，不要一段话里推拉好几次
- 摇镜——横向扫过展示环境或多个物体时用，不用于对着人脸摇

一句话原则：**能靠剪辑切换景别解决的，不要求老板现场运镜**；运镜只用在固定+切换景别做不到的效果上，降低拍摄难度。

**居家单人拍摄布光要点**（不是影棚级布光设计，只给可执行的检查项）：
- 光源正对脸（顺光）最简单可靠：面对窗户或主光源拍，避免逆光把脸拍暗
- 侧光可以增加立体感，但阴影不能挡住半张脸，暗部细节仍要看得清
- 阴天/室内灯光偏暗时，优先靠近窗户或加一个平价环形补光灯，不用后期强行提亮（提亮会拉高噪点）
- 拍屏幕操作/录屏内容时确认环境光不会在屏幕上反光遮挡关键信息

这份词汇表只覆盖真人口播/教程视频的常见拍摄场景；需要更复杂的镜头调度或多机位时，直接跟老板明确说明超出手机单人拍摄能力范围，不要硬套词汇表勉强设计。

## 口播表演指导

导演在 `拍摄提示词.md` 和 `shot-checklist.md` 中按需写入：

### 录前状态

1. 身体轻微抖动或活动，释放紧张。
2. 正式录制前随便说几句，完成声音热身。
3. 把镜头想成一个具体朋友，不做“对全世界演讲”的腔调。
4. 录前再问：这段具体怎样帮助观众？

### 说话节奏

- 使用短句为主，长短句交错，不把书面稿一口气念完。
- 重点前后可以留停顿，但不把“停 1 秒”机械套在每句话上。
- 重要结论可向下收束，疑问和轻松段落可自然变化；不固定一种语调。
- 句尾不要无意识掉音，除非该段本来就需要脆弱、犹豫或留白。
- 保留亲和力与确定性：像朋友说话，同时真正相信有证据支撑的部分。
- 正式录制前对着镜子多顺几遍稿子，练出"跟朋友聊天"的交流感，停顿和语气会自然带出来；嘴巴张开、每个词读满，语速偏慢的话后期加速到 1.1-1.2 倍即可，不用现场硬加快。

### 声音技术层（Julian Treasure，2026-08补充）

上面"说话节奏"讲的是语句结构和交流感，这里补一层更底层的声音本身：内容和演绎都对了，声音技术不到位照样打折。

**该避开的七个习惯**（讲戏时发现老板录制状态出现这些，直接提醒重录该句）：说闲话（背后议论不在场的人）、评判、消极、抱怨、找借口、夸大其词、教条（把观点讲成事实）。

**该追求的四个基石（HAIL）**：诚实——说真话；真实——做自己，不端"对全世界演讲"的腔调（呼应上面"把镜头想成一个具体朋友"）；正直——言行一致；善意——真心希望观众好。四条里"善意"和口播表演指导开头"录前再问：这段具体怎样帮助观众"是同一件事。

**可直接调的五个声音参数**：
- 音区——从鼻腔（细）到喉咙（日常）到胸腔（有分量），偏低沉的声音心理上更易被联想到权威。
- 音色——偏爱丰富温暖的质感，可通过呼吸和发声练习改善，不是天生固定。
- 韵律——说话的抑扬顿挫；全程一个音调难以听下去，陈述句结尾用疑问句语调上扬是常见坏习惯，讲戏时要指出。
- 语速——快制造兴奋，慢强调重点，极致是沉默，不用"嗯""啊"填满空隙。
- 音量——大声制造兴奋，安静反而让人更认真听。

**六个发声热身**（补充到"录前状态"第2条"声音热身"的具体动作）：举双臂深吸气长叹"啊——"；嘴唇"巴巴巴巴"；嘴唇振动"brrrr"；舌头"啦啦啦啦啦"；卷舌"儿——"；"警笛音"从高滑到低。只能做一个时选警笛音。

### 可信度

- 观点后安排证据镜头：界面、实物、操作、来源、前后状态或真实结果。
- 脆弱经历可以建立信任，但问题、失败、时间和转变必须真实，不能为了套故事补造。
- “看逐字稿”不是固定动作；根据提词器位置和老板状态，决定逐句、分段或提纲录制，避免眼神持续漂移。

### 演绎层：写对不等于念对

文案结构对（钩子/证明/收尾都到位）只是内容层及格线，照稿干念效果照样打折——念对是演绎层的加分项，讲戏时要单独盯：

- 关键词双通道视觉强调：主字幕用不同字体样式标出重点词，再在人物头顶等空间加一条带动画音效的强调字幕，不要只依赖口播语气。
- 全程坐着说话太"干"：内容提到具体动作（如"写脚本"）就切一个本人真的在做这件事的镜头，让理解证据不止停留在口播和坐姿正对镜头。
- 后期音效/特效按情绪分类使用，克制不堆砌：关键帧+放大制造"要放大招了"的预期感，聚焦效果制造"仔细听"的注意力收束，两者都是锦上添花，不是必选项。

### 个人视觉标识

- 外貌、布景和机位服务于账号一致性，不制造刻板着装要求。
- 稳定保留 1-2 个识别元素即可，例如固定背景、机位角度、道具或开场动作。
- 定风格时可以先收集自己认为好看的视觉参考，用 AI 反推对方大致用了什么机位/参数来模仿同款视角；风格一旦定稳，后续每次拍摄能省决策时间，也变成账号自己的"水印"。

## V-A-V 与理解证据

开拍前做两遍测试：

1. 静音看首帧/前一秒：能否理解主题或结果？
2. 开声音再看：第一句话与画面是否在讲同一件事？屏幕文字是否只是确认，而不是增加第四个信息？

抽象概念优先配“理解证据”，而不是装饰性 B-roll。没有帮助理解的画面宁可不用。

## 高级动效的导演语法

动效不是“让元素动起来”，而是用运动组织观众视线、强化理解证据。需要设计动效的内容段先选一个主动作动词：

- **展开**：页面、流程、文档逐层显现。
- **聚焦**：镜头和界面共同指向按钮、字段或关键词。
- **组装**：纸片、步骤、模块按依赖关系进入并落位。
- **转化**：草图、Prompt、输入状态变成真实输出。
- **验证**：结果、成功提示、前后差异成为唯一主焦点。
- **收束**：多条信息归并成结论、记忆锚点或品牌落位。

禁止只写“弹出、放大、有高级感”。每个重点动效镜头必须写清：

```text
视觉目标：
主焦点：
起始状态：
主动作与次级动作：
运动路线：
持续时间与错峰顺序：
预备、越位、落稳和结果保持：
镜头运动：
音乐变化：
音效触发动作：
静音观看验收：
```

同一画面只保留一个主动作；背景、次级卡片和装饰只能延迟响应或弱响应，不得与主焦点同时争抢注意力。结果出现后必须留出看清时间，不因追求快切立即离开。

### 竖屏屏幕内容

9:16 屏幕演示使用中央主舞台：主 UI、演示焦点和结果放在中央主要安全区；标题/步骤在上方，结论或状态在下方，边缘纸片和道具只承担纵深。运动优先沿纵向展开或推进；允许前景快、中景正常、背景慢的视差，但不得遮住按钮、光标、字幕或结果。

## 故事节拍转成镜头节点

- 前后对比：Before → 触发变化的动作/证据 → After。
- 挑战：目标与规则 → 障碍 → 调整动作 → 结果或悬念。
- 胜利：结果先出 → 可见证据 → 真实情绪反应。
- 日常/个人更新：身份与目标 → 意外问题 → 处理 → 收尾。

文案里的“但是/因此”必须在画面上发生变化：障碍出现、行动改变或证据揭晓，不能只靠配音制造戏剧性。

## 设计旋钮（每个视频定调用）

在开拍前确定三个值，统一全片视觉风格：

| 旋钮 | 低值 | 高值 |
|---|---|---|
| VARIANCE 1-10 | 常规构图、稳定 | 非常规角度、打破框架 |
| MOTION 1-10 | 少动、静置镜头 | 多运动、快切、动态 |
| DENSITY 1-10 | 大量留白、简洁 | 信息多、画面丰富 |

三个值是项目设计决策，不是平台效果公式。根据内容成本、账号风格和待测变量设置。

## 讲戏本规范

输出到 `03outputs/讲戏本.md`，每场标注：

```text
### 场一：开头（00:00 - 00:05）
- 制作方式：实拍
- 画面：场景 + 可拍动作
- 镜头：景别 + 角度
- 声音：语速 / 语调 / 停顿
- 理解证据：观众需要看见什么
- 意图：这场如何推进承诺链
```

## 分镜标注规范

使用导演 SKILL 规定的统一表格，制作方式限定为：`实拍`、`录屏`、`轻量动效`、`外部素材`、`AI生成`。

AI 生成镜头同样只写可见物理动作，给出参考绑定和可判断的验收标准；不能用“高级、震撼、有电影感”代替画面说明。

## 可选资料模型：多巴胺阶梯

> 仅在项目明确采用该来源模型时参考；不是导演默认检查项。默认仍检查主题清楚、证据可见、结果兑现和真实表达。

| 层级 | 导演做什么 |
|---|---|
| L1 刺激 | 首帧主题/结果清楚，必要时用动作、颜色或亮度打断滑动 |
| L2 迷恋 | 抛问题时给匹配的近景或证据，不用无关刺激 |
| L3 预期 | 用动作与证据推进，不一次性泄露全部答案 |
| L4 验证 | 揭晓时让观众真正看见结果 |
| L5 喜爱 | 通过眼神、能量、真实局限和稳定风格建立亲近感 |

“多巴胺峰值”“视觉效率倍数”等强心理学说法仍是资料主张，不进入镜头硬标准。
