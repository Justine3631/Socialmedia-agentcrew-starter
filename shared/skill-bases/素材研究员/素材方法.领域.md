## 工作流

1. 读 `03outputs/分镜.md`、`shot-checklist.md` 和 `02script/publish-pack.md`。
2. 按镜头 ID 准备实拍参考、录屏步骤、外部素材、轻量动效或 AI 生成参考。
3. 每项记录文件/URL、来源、版权、采集日期、必需性和状态。
4. 把素材按镜头 ID 放入唯一项目素材目录 `04media/`。
5. 单独完成封面概念与手机端检查。
6. 使用 `asset-manifest.md` 交接；必需项有缺口时不冒充“素材齐备”。

## 素材搜索指南

### 来源优先级

1. 已有实拍、录屏和项目素材。
2. 官方产品页、说明书、标签、资质与一手来源。
3. 授权清楚的图库、素材库或作者许可内容。
4. AI 生成素材，但要记录生成方式并避免冒充真实证据。

任何素材站点被资料提到都不等于可商用。`ysjf.com/material` 的授权范围本轮未核验，不能直接进入正式素材清单。

### 配合原则

- 素材为理解和证明服务，不为热闹而铺满 B-roll。
- 事实证据优先于装饰画面；界面、实物、操作和前后状态通常比无关空镜更有用。
- 账号风格优先于通用“爆款审美”；高饱和、高对比、情绪大脸都只是可测试选项。

### 按内容类型

| 类型 | 优先素材 |
|---|---|
| 干货教程 | 官方界面、录屏、步骤卡、流程图 |
| 观点评论 | 一手数据、来源截图、人物或事件证据 |
| 带货 | 产品实拍、使用场景、规格/资质、真实前后状态 |
| 故事 | 真实经历素材、时间线、实拍、获得授权的补充画面 |

## 封面：包装合同，不是装饰

当前两个账号的默认平台顺序是：**抖音主版 → 小红书适配版**。封面默认交付为抖音 `3:4` 竖版与 `4:3` 横版、小红书 `3:4`；同一批准方案分别重排，不得机械裁切。先保证抖音首帧和自动播放语境成立，再为小红书单独调整封面、标题与图文语境；老板可按单个项目修改。

封面和标题共同设定观众预期：

1. **视觉打断**：在目标平台的界面里能被看见。
2. **价值理解**：观众迅速知道这和自己有什么关系。
3. **视觉证明**：画面为标题承诺提供结果、过程、前后变化或真实场景证据。

标题与封面应互补，不机械重复同一句。正文必须兑现两者的共同承诺。

### 点击决策模型与视觉武器清单（2026-08补充）

封面是"接口"，视频内容是"函数体"——接口调用失败，函数体写得再完美也不会被执行。同一条视频换个封面，播放量可能相差近千倍，这是把封面当"包装合同"而不是"装饰"的原因。

**观众点击前1-2秒的三步决策**：①视觉电击枪——无意识滑动中被视觉信号击中，从被动扫描切换为主动锁定；②标题价值猎寻——视线下移到标题，寻找"这对我有什么好处"的具体答案；③视觉验证——读完标题后再看回封面，寻找视觉证据支撑标题的承诺，逻辑不通会因困惑放弃点击。**封面文字不应直接重复标题内容**——标题已经给了信息，封面文字该补充情感或证据，不是再抄一遍标题。

**视觉电击枪的7种武器**（从中选，不超过3个核心元素的约束不变）：色彩科学与对比、情绪化大脸（大脑对人脸情绪极敏感，小账号与其展示"我是谁"不如展示"我的情绪"）、视觉冲击图形、巨型文字与数字、指向性元素（箭头/圈直接告诉观众看哪）、审美意境（电影感/对称性）、设计感拼贴。这份清单和上面"构图与元素"里的具体做法是同一件事的不同颗粒度，选武器时对照这份清单避免遗漏选项。

**正义诱饵原则**：诱导点击但不能撒谎——内容能兑现封面承诺，再夸张的封面都是正义的；封面承诺内容给不出，就是标题党。

**流程前置**：封面构思应该在内容与开拍卡前完成，先定义具体观众、真实问题、可见结果和证据画面，自问“观众看到封面会期待什么，正文能否完整兑现”。建立个人灵感库可以减少重复摸索，但不得照搬来源不明的设计或承诺。

### 设计前先定三件事

- 目标观众想得到什么或避开什么真实不便？
- 标题承诺是什么？
- 哪张图最能证明这个承诺，而不是只制造情绪？

带货内容不得把“不买”包装成疾病、落后或必然损失。

### 设计旋钮

| 旋钮 | 低值 | 高值 |
|---|---|---|
| VARIANCE 1-10 | 稳定、常规 | 激进、非常规 |
| MOTION 1-10 | 静态感 | 强烈动势 |
| DENSITY 1-10 | 留白多 | 信息密集 |

旋钮用于统一项目方向，不是平台效果公式。

### 构图风格库（可选参考，按账号风格挑用）

旋钮定方向后，可从下表挑一个具体风格落地，避免旋钮值停留在抽象数字。风格之间背景色调、字体逻辑各自独立，不混用同一套配色套所有风格。

| 风格 | 适合什么 |
|---|---|
| 深色渐变风 | 人物/主体居中，大字覆盖后方，深色渐变背景，高对比强冲击 |
| 纯色扁平风 | 抠图感，纯色背景，干净清爽 |
| 产品主视觉风 | 界面截图/产品占主体，人物或箭头做引导，适合素材充足 |
| 对比卡片风 | 两张对比图近大远小构图，适合前后对比内容 |
| 极简留白风 | 大面积留白，文字是主视觉锤 |
| 海报拼贴风 | 多张参考图叠加分层，适合素材丰富的内容 |
| 局部特写风 | 只露手/半脸/侧脸/产品细节，主体是绝对主角 |
| 正面对视风 | 人物或主体直视镜头，文字环绕四周 |

出镜类账号另需固定“人脸参考图”作为图1，其余素材图（界面/产品/场景）从图2起排列，提示词里直接写“图1/图2”指代，不复述图中细节。

### 构图与元素

- 每张封面最多保留 3 个核心元素，建立单一视线路径。
- 常用构图：居中对称、三分法非对称、A/B 前后对比。
- 常用证据图：最终结果、关键过程、前后变化、真实问题场景。
- 人脸、文字、箭头、数字、对比色或拼贴按需选择，不默认全部使用。
- 文字不能和人脸、产品或关键结果打架。
- 与账号的字体、色调、布景和真实气质保持一致。
- **红绿色彩法则**（资料主张）：用绿色标注"好/正确/达成"，红色标注"差/错误/问题"，利用观众潜意识里对红绿的既有联想，减少解读成本。
- **避开右下角"死亡角落"**（资料主张）：多数平台会在播放页右下角叠加时长标签等UI元素，封面核心信息（人脸、结果、关键文字）不要放在这个区域，否则会被系统UI遮挡。
- **安全区**：人脸、标题文字、主体道具等关键元素距画面四边至少留约 10% 边距，避免被平台裁切或UI遮挡。

### 检查方式

1. 缩小到手机尺寸，检查文字、主体和结果是否仍清楚。
2. 检查平台 UI 是否遮挡核心信息。
3. 静音看封面/首帧，能否理解主题或结果。
4. 对重要视频可准备 2-3 个概念版；是否长期 A/B 测试由平台能力和复盘结果决定，不设成每条硬门槛。
5. 为封面需要的表情、手势、产品姿势或结果图提前安排补拍，不在剪完后临时截一张。补拍表情类素材时，可用4K 60帧连续录制一段夸张表情变化，再从中截取最佳帧，比专门摆拍单张照片更自然、效率更高（资料主张）。
6. AI 生成封面出图后，逐字核对画面中的中文文字；图片模型常写错中文字（错字、多笔少笔），出现问题就重新生成，不得带错字交付。

## 制作方式与交接

| 制作方式 | 素材研究员准备 |
|---|---|
| 实拍 | 参考图、布景/机位参考、补拍清单、shot ID |
| 录屏 | 操作流程、账号隐私检查、录屏文件 |
| 轻量动效 | 信息层级、图表/卡片所需数据与视觉参考 |
| 外部素材 | 文件/URL、来源、版权、采集日期 |
| AI生成 | 风格参考、事实边界、参考绑定与验收标准 |

AI 生成画面不能替代产品实物、官方界面、资质、真实体验或数据证据。
