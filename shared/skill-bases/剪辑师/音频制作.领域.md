## 混音电平：固定处理顺序

**对白/口播先定电平 → 音效第二 → 音乐最后铺。** 常见业余错误是反过来先铺音乐再塞人声，导致大部分电平问题——顺序对了，很多问题自动消失。

**三层电平目标**（专业DAW参考，剪映等后端按等效刻度换算，账号已有起始参考见`剪辑方法.领域.md`）：
- 人声/口播：−6dB 到 −12dB（先定这个，其余围绕它调）
- 音效：−10dB 到 −20dB（听得见但不能盖过人声）
- 背景音乐：有人说话时 −20dB 到 −30dB（应该是"感觉到"而非"听到"），无人说话间隙可抬到 −12dB 到 −18dB
- 成片峰值控制在 −3dB 以下，为平台后续处理留余量

**Audio Ducking（自动闪避）**：有人说话时自动压低背景音乐，说完自动抬回去。是性价比最高的单一混音技巧，剪辑后端若有此功能优先用，没有则按上述电平手动分段调整。

**进阶分离技巧**：不是简单压低音乐音量给人声让路，而是挖空背景音乐里人声所在的中频段"口袋"，让人声自然嵌进这个空间，比单纯降低整体音量更分离、更有层次。

## 响度标准化（LUFS）

电平之外的独立标准，衡量整条视频的客观响度而非单个元素音量。目标值：**YouTube/多数流媒体约 −14 LUFS，播客约 −16 LUFS，广播标准 −23 LUFS**。平台上传后会自动把响度归一化到目标值，混得比目标响度更大声没有意义，只会白白损失动态范围。

**操作顺序**：完成剪辑和粗混（靠耳朵判断音乐相对人声是否吵）→ 整条混音导出成一条立体声轨 → 测量当前整体响度 → 拉响度前检查真峰值余量（通常预留至少1.5dB防止削波，余量不够先用压缩器压低峰值）→ 执行响度标准化。

**关键提醒**：响度标准化只在混音全部完成后对最终成品做一次，不在剪辑过程中对单独片段做标准化；标准化后可能暴露之前被掩盖的呼吸声、口腔杂音等细节，处理完这些后要重新测一次响度，因为改动会影响之前测好的数值。

导出规格：48kHz / 24-bit WAV / 立体声。**验收必须过一遍手机外放**——手机喇叭几乎重放不出500Hz以下的声音，耳机里听感好的混音，外放可能发现低音全没了、中频糊成一团，这是最常被忽略但最重要的QC步骤。

## 配乐选取与剪辑

**看波形图而不是听完整首歌**：一首配乐通常3-4分钟，直接看波形图——起伏大、中间有明显"断点/悬崖"的曲子最好剪，那些空白/低幅度处就是天然剪辑点；波形从头到尾混在一起没有明显起伏的曲子很难剪断，不建议选。同样逻辑可用于粗剪原始素材：看素材本身的音频波形而非完整看画面，说话声和关键动作声在波形上是不同形状，能跳过完整观看直接定位保留片段。

**同一首歌人声版+纯音乐版拼接**：解决一条视频用好几首歌导致情绪脱节的问题。先用有人声版本铺一段，在鼓点/打击乐处"重音对重音"剪断，接上同一首歌的纯音乐版（Instrumental）做背景铺垫，听感无缝。

**乐器音色对应情绪标签**（选曲感性依据）：钢琴叙事抒情、小提琴多变、大提琴忧伤低沉、手风琴活泼轻快、口琴带年代感。**留白本身也是配乐手段**——重要情绪节点前故意大段留白，能让后面的音乐冲击力更强，不是所有片段都要铺音乐。

**BGM风格匹配原则**：BGM情感基调要匹配内容基调（情感类不用嘻哈，干货类不用节奏太强）；BGM节奏要匹配画面剪辑节奏（先梳理素材起承转合，再按这个节奏找配乐，重音对重音）。**爆火BGM≠流量保证，甚至可能反效果**——用户对爆款BGM会"刷到疲劳"产生条件反射式划走；调性不搭硬凑更易引起反感。BGM不能喧宾夺主，为内容服务而非抢戏。

## 音效设计：三阶段法

给画面配动画和给动画配音效是同一件事的两半——视频"不够吸引人"很多时候缺的不是更多动画，是声音设计。

1. **运动阶段**：弹出、滑入、缩放、划出配Whoosh呼啸声。**关键细节：whoosh音效峰值要对齐动画运动模糊最强的那一帧**，不是对齐动画开始或结束时间点——这是最容易被忽略但效果差异最大的操作细节。
2. **材质阶段**：弹窗、图形动画、文字写出效果配数字点击声、键盘声、荧光笔划过声，作用是引导视线、给静态动画注入生命感。
3. **Riser/Hit阶段**：蓄力段落前用Riser（渐强音）堆积紧张感，转折/爆点处用Hit（重音）释放。

**分频层叠**：单个whoosh配小动作还行，配大幅度动作显得单薄，把不同频段的音效叠加（像千层蛋糕，每层贡献独特频率）做出更饱满声音。

**先定风格再挑音效**：粗犷厚重低音撞击不适合企业宣传片，清脆铃铛不适合街头风格——先确定整条视频音效风格，再挑具体音效，不逐个单独匹配。

**通用用法清单**：开场用音效抓注意力、音画精确同步、多音效分层叠加、用环境音掩盖录音瑕疵、强调关键瞬间——以及最容易被忽视的一条：**克制使用，用太多反而让观众疲劳**。

**内容类型决定音效密度**：教程/知识类应清晰克制，几乎不用音效，装饰性元素会和理解争夺注意力；短视频/社交类相反，默认观众手机外放没戴耳机，音效可短促响亮、密集卡点。

## 版权判断：四条路径风险递减、成本递增

| 路径 | 说明 | 风险 |
|---|---|---|
| 直接使用原曲 | 能用任何歌 | 会被平台版权系统识别claim，可能收益转走或限制播放，只适合不追求变现的场景 |
| 付费买授权 | 订阅平台拿同类风格音乐 | 拿不到顶级艺人原曲，但授权清楚 |
| 免费+需署名 | 独立艺人放下载链接换署名 | 只是君子协议非法律保障，原作者后续签约唱片公司可能反过来claim旧视频 |
| 自己创作/AI生成 | 自己就是版权方 | 最安全，成本是学习时间或生成质量不稳定 |

**授权类型速查**（比SKILL.md现有CC0/CC BY判断更完整）：

| 类型 | 含义 |
|---|---|
| CC0 / Public Domain | 免费使用，无需署名 |
| CC BY | 免费使用，需署名 |
| CC BY-ND | 不允许修改或remix |
| CC BY-NC | 仅限非商用，变现频道不能用 |

"Royalty-free"不等于"完全免费"——指一次性付费买断使用权，之后无限次使用无需再付费，是商业模式不是不要钱。

**实用建议**：变现频道使用任何素材前先确认商用授权；保留每份授权记录（截图+下载凭证），版权申诉出现在数月之后时，这份记录是唯一能快速解决问题的凭证——与SKILL.md「音乐与音效主动检索」第6步 `source-manifest.md` 记录要求一致，不是新增动作。

## 素材获取渠道（SKILL.md 现有 Pixabay/Mixkit/Freesound 之外的补充选项）

**中文免费素材站**：爱给网（600万+免费音效，支持格式/时长筛选）、耳聆网、淘声网、声音网。国内站同样要逐站核实"免费下载"是否等于"可商用"。

**英文免费素材站**：Free Music Archive（欧美BGM）、sound bible（1000+音效，标签和版权说明详细）、DOVA-SYNDROME（日系BGM）、MUSOPEN（古典音乐，多数不受版权保护）、OpenGameArt（游戏音效，GPL协议）。

**付费订阅平台**（预算允许时）：YouTube Audio Library（完全免费起步款）、PremiumBeat（单曲授权约$49，条款简单）、Artlist（编辑评价最高）、Epidemic Sound。

**自己生成**：Meta开源AudioCraft（MusicGen文本到音乐、AudioGen文本到音效），代码MIT协议但**模型权重是CC-BY-NC协议（非商用）**，变现账号使用前需额外确认商用授权路径，不能默认"开源=可以随便用在赚钱的视频里"。需要Python环境搭建能力，偏技术向，非日常首选。

不论从哪个渠道选，最终都要落回上面"混音电平"和"响度标准化"两节才算完整。
