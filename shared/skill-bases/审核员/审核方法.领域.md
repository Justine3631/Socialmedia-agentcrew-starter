# 审核方法.领域.md

> 审核员的共享审查方法。账号合规规则仍以 `accounts/<账号>/skill-base/审核员/account-rules.md` 为上位约束。
>
> 基于：现有审核闸门、乐高框架、2026-07-15 自媒体知识目录第一轮学习
> 最后更新：2026-07-30

## 一、承诺链

沿着一条链检查：

`标题/封面 → 首帧/屏幕文字/第一句话 → 正文证据 → 最终答案/结果 → CTA/商品`

阻断情形：

- 包装承诺大于正文交付，或中途偷换问题。
- 标题讲 A，CTA 或商品却卖 B。
- 前后对比、结果、时间、经历或引语缺少真实证据。
- 用无关空镜冒充观点证据。

## 二、三钩一致与一遍听懂

- 文字钩子、首帧画面和第一句话是否指向同一主题与价值？
- 第一次听是否只有一种合理理解？
- 是否主题延迟、复杂句过多、冷启动术语、多个无关承诺或没有即时价值？
- 第一人称不是问题；问题是观众看不见这件事与自己的关系。

不预设 Text、Visual、Spoken 的跨平台固定排名；按项目目标与实际平台审查。

## 三、证据类型

必须区分：

- 官方事实与当前来源。
- 第三方研究或案例。
- 老板的个人经历与单次体验。
- 类比、课程观点和待验证假设。

类比不能当证据，个人体验不能自动推成普遍结论，平台机制和精确数字没有当前一手来源时必须标明不确定性。

## 四、反操纵检查

以下内容不能因为“可能带来评论或点击”而放行：

- 制造敌人、虚假争议、极端化表达。
- 恐惧操纵、夸大损失、伪造紧迫性。
- 捏造百分比、用户数量、案例、背书、销量或“多数人都在用”等社会证明；真实数字缺少来源、范围或日期。
- 把“如果”强行改成确定会发生的“当”。
- 用秘密、反派、负面框架包装没有证据的结论。
- 带货内容制造健康焦虑、保证功效或暗示不买就会生病/落后。

可以观点明确，但必须真实、可证、与账号气质一致，并允许合理边界和反例。

## 五、口播与封面

默认同时检查抖音主版与小红书适配版。两版可以包装不同，但事实、核心承诺、合规边界与最终交付不能互相矛盾。

### 口播

- 情绪、表情和语气是否与内容一致，而不是机械背稿？
- 是否存在句尾无意识掉音、重点不清或夸张经历无证据？
- 有意义的停顿是否被保留，节奏是否仍自然？

### 封面

- 是否有单一视线路径，核心元素是否过载？
- 文字是否只重复标题，没有补充价值或证据？
- 手机尺寸是否可读，平台 UI 是否遮挡关键信息？
- 高饱和、情绪脸、箭头、数字是否服务账号和内容，而不是通用模板堆叠？

## 六、Lego 诊断

发现问题时定位到具体组件：Format、Topic、Seed、Substance、Spoken Hook、Visual Hook、Text Hook、Story Structure、CTA、Visual Layout、Elements。

一次审核可以发现多个问题；进入复盘实验时只选择一个主要变量，避免无法归因。

## 七、动效与声音质量

存在设计动效时，按时间码检查：

- 是否有唯一主焦点和可追踪的视线路径，还是所有元素同速同曲线一起动。
- 动画是否对应展开、聚焦、组装、转化、验证或收束等语义动作。
- UI、纸张、真人、字幕和镜头是否保持不同运动身份。
- 是否有预备、错峰、落稳和结果保持；结果是否来得及看清。
- 声音峰值是否对准接触、锁定、完成或验证动作，而不是机械贴在剪辑点。
- 音乐、材质声、交互声和结果声是否有主次与留白；是否存在每次切镜都加 whoosh、重低音压住人声或音效过密。
- 9:16 屏幕内容的 UI、按钮、光标、字幕和结果是否位于主要安全区。

审美偏好本身不作为阻断。主焦点混乱、关键操作被遮挡、结果来不及看清、声音压住口播或声画明显错位，属于可执行性/成片质量问题；按影响程度列为阻断或建议。
