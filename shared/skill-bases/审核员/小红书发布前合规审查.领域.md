# 小红书发布前合规审查.领域.md

> 用于小红书成片/笔记的发布前审查。它补充平台风险检查，不替代账号规则、事实核验或独立审核闸门。
> 结构参照 `抖音发布前合规审查.领域.md`，风险面按小红书平台特点调整，不跨平台混用结论。
> 最后更新：2026-08-03

## 一、结论边界

- 不预测平台一定通过，不给"通过概率"，不推测未公开算法或限流机制。
- 曝光/互动数据低不等于限流。只有平台通知、笔记状态或账号处罚记录能确认官方限制；否则写"分发异常/表现不佳假设"。
- 先判断合规阻断，再给内容质量建议；制作精良不能抵消违规。
- 材料未提供时写"未提供/无法核验"，不能写成"未发现问题"。
- 审核员只指出问题、最小整改方向和复核动作，不代替编剧、导演或剪辑师修改原产物。

## 二、证据与依据

每条发现都记录：

1. **作品证据**：文件、时间码、原句或截图；涉及画面时描述可见对象。
2. **依据类型**：
   - `官方明文`：当前小红书社区公约/规则中心页面或用户收到的平台通知可定位到明确要求。
   - `风险推断`：依据规则与作品证据推导出的可能风险。
   - `质量建议`：改善理解、留存或体验的建议，不冒充平台规则。
   - `待核验`：缺少授权、资质、来源、上下文或官方现行规则。
3. **来源记录**：规则名称、发布机构、URL、采集日期；有生效日期时一并记录。
4. **最小整改**：只说明需要删除、降级表述、补标识、补证明、遮挡或重写的位置。
5. **复核动作**：修改后用肉眼或材料核对即可执行的检查。

官方页面无法访问、条款状态不明或来源过期时，标为 `待核验`；不得用违禁词表、经验帖或平台传言补成官方规则。用户收到的具体平台通知优先作为该笔记的个案证据。

## 三、发布闸门

沿用工作台两档结论，不另设分数：

- **修改后复审**：存在任一阻断项，或关键材料不足以排除高风险。
- **通过**：阻断项为 0，所有待核验事项均不影响发布安全；建议项可以保留。

以下默认属于阻断项：

- 明确违法、欺诈、色情、严重暴力、自伤诱导或严重侵害未成年人权益。
- 虚假重大公共信息、泄露敏感个人信息、严重网暴或明确侵权且无授权。
- 商品、健康、财经、法律等高风险表达缺少必要资质、证明或关键限制条件。
- 确定疗效、收益、销量、"最""第一""根治""人人适用"等广告法极限词或客观承诺无法证明。
- 商业合作（品牌植入、带货）未按小红书要求完成利益关系披露，或明显规避平台报备走私下导流。
- 关键画面、图文、封面、商品信息或授权材料缺失，无法完成必要检查。

低清、封面文字过密、标题与内容轻度错位等通常是建议项；但严重到造成误导、核心信息不可辨或承诺无法兑现时升级为阻断。

## 四、完整风险面

发布前逐项检查并写明"通过 / 建议 / 阻断 / 不适用 / 无法核验"：

1. 违法交易、诈骗、赌博、毒品与危险行为。
2. 色情低俗、暴力、自伤与令人不适的画面或文字。
3. 未成年人权益、隐私、肖像、网暴与个人信息。
4. 版权、音乐、字体、图片、视频片段及第三方品牌授权。
5. 广告法极限词与违禁词（"最""第一""根治""国家级""人人适用"等无法证明的绝对化表述）。
6. 商品类别、商业合作披露、价格、功效、销量、产地与资质证明。
7. 医疗健康、财经、法律、教育等专业内容的资格、来源与边界。
8. 站外导流、私下联系方式、交易路径与不当营销（区分平台允许的合规引导与规避报备的硬广）。
9. 标题、封面、正文、图片、标签之间的承诺一致性；标题党（标题与实际内容严重不符）风险。
10. 事实来源、数据时效、个人体验与普遍结论的区分（避免"我用了都说好"变相暗示疗效或普遍适用）。
11. 图文笔记的图片信息、视频笔记的画面声音字幕是否造成误导或无法理解。
12. 笔记形式是否明显同质化于批量营销内容（模板化措辞、大量雷同笔记特征），存在被判定营销号/虚假种草风险。

## 五、当前规则核验

涉及阻断判断或高风险场景时，发布前联网核对现行官方来源：

- 优先小红书社区公约、小红书规则中心、小红书电商/蒲公英商业合作规范及用户收到的平台通知。
- 医疗器械、保健食品、普通食品等商品类别与批准信息，同时核对对应国家主管部门的官方数据库或商品法定材料。
- AI 产品版本、价格和能力核对产品官方文档；授权状态核对授权文件或权利方说明。
- 记录实际查到的页面，不把搜索摘要写成规则依据。

若联网不可用，所有可能改变发布结论的现行规则与资质问题都保留为阻断或待权威来源确认，不凭旧快照放行。

## 六、已发布作品的限制诊断

收到平台通知时先按严重度分级，分级决定处理节奏，不是所有通知都同等紧急：

| 严重度 | 常见表现 | 建议处理节奏 |
|---|---|---|
| 轻度 | 仅限流/不推荐，笔记仍在 | 核对内容后再决定是否调整，不必立刻下架 |
| 中度 | 笔记被下架+账号警告 | 24小时内核对通知原文，决定是否申诉或整改 |
| 重度 | 账号功能受限/临时封禁 | 尽快提交申诉，附证据材料 |
| 严重 | 账号永久封禁 | 只有确认误判时才申诉，附完整证据链 |

- 有平台通知或状态证据：记录通知原文、时间、处置范围和申诉入口，称为"官方限制"。
- 无平台通知：把合规风险与内容表现分开；列出假设、支持证据、反证和补充材料，不确认"限流"。
- 仅有低曝光/互动：优先与同账号、同平台、相近类型和相同内容形式的历史基线比较，再交给复盘员分析选题、封面、标签、发布时间和混杂变量。
