## 复盘工作流

### Phase 1：发布登记
老板说"发布了" → 先确认审核通过，并确认 `prediction.md` 在看到数据前完成；再从 `shared/templates/video-project/07publish/publish.md.template` 创建 07publish/publish.md，记录时间/平台/链接，用状态工具更新为"已发布"

### Phase 2：数据采集
老板说"复盘一下" → 问老板要平台原始数据，填写 publish.md 的默认 T+1/T+7 表。分发仍变化或异常时补 T+3；常青搜索、带货长尾或假设未收敛时补 T+30。AI 账号重点记录完播、平均观看、收藏和关注；带货账号额外记录商品点击、成交和负面反馈。

### Phase 3：复盘分析
从 `shared/templates/video-project/08retro/retro.md.template` 创建 `08retro/retro.md`，先对照发布前预测，再分析三个层次，并记录四项效率：立项到发布、老板批准卡确认次数、发布前返工次数、状态/规则冲突次数。

### Phase 4：假设登记与升级
单条视频只产生待验证假设，写入 `accounts/<账号>/learning-log.md`。两条独立视频支持时标为“临时规律”，仍留在学习日志；三条以上且无明显反例时才合并进对应岗位现有的 `account-rules.md`。老板明确确认的长期偏好可以直接写入；不要为每次复盘创建零散规则文件。

每条假设同时标记证据状态：`资料主张`、`官方确认`、`本账号观察`、`临时规律`、`稳定规则` 或 `已被反例推翻`。

## 复盘的三个层次

### 层一：数据层（是什么）
- 播放量 = 流量总量
- 完播率 = 内容留存力
- 互动率（赞/评/藏/分）= 内容价值感
- 三个维度一起看才有意义

### 层二：内容层（为什么）
- 高播放低互动 → 标题/封面抓眼球但内容没留住人
- 低播放高互动 → 内容好但选题太窄
- 完播率高 → 节奏和结构对了
- 评论区反馈 = 最直接的"观众在想什么"

### 层三：规律层（下次怎么办）
- 提炼成可复用的原则
- 原则要具体（"反常识类标题数据更好" vs "标题写好一点"）
- 写入技能库时有数据支撑

## 乐高框架诊断工具

数据差的视频 → 拆11块砖找问题：
- Format选错了？
- Seed没说清楚？
- Text Hook不够吸引？
- Substance太水？
- Story Structure混乱？

数据好的视频 → 拆11块砖提取规律：
- 钩子强？→ 告诉编剧
- 主题买账？→ 告诉提案师
- 结构好？→ 告诉编剧可固定

实验变量统一使用 Lego 名称。不要同一期同时更换 Topic、Hook、Story、Visual Layout 和 CTA 后，再声称某一项导致结果。

## 先按内容目标选指标

| 主要目标 | 优先观察 | 辅助观察 |
|---|---|---|
| 曝光 | 播放、目标人群占比/评论信号 | 观看与互动质量 |
| 关注/权威 | 关注/播放、收藏、目标问题评论 | 完播、平均观看 |
| 商品点击 | 点击/播放、目标购买意向 | 观看、评论与负反馈 |
| 成交 | 成交/播放、成交/点击、退款/售后 | 播放与点击 |

不把不同平台、时长、内容类型和商业目标的视频直接横向比较。

### 目标流量质量

除总播放外，记录：

- 评论是否来自目标观众，是否出现真实操作卡点或购买问题。
- 是否有人准确复述核心观点，说明内容被理解。
- 是否出现错误人群、误解、健康焦虑或与账号定位无关的争议。
- CTA 后的点击、关注或成交是否与内容承诺一致。

## 账号整体复盘维度

### 受众错位检测
检查近期视频的主题与目标人群。如果某条偏离主赛道，比较后续目标评论、关注转化与观看数据是否变化；没有数据时不声称存在“混合采样伤害”。

### 分发停点观察
资料主张的区间（抖音五级流量池：0-200→200-2000→2000-2万→2万-50万→50万+；小红书CES门槛：≥50进初级池80-500曝光、≥200进终极池5000-2万、≥800可能爆款）不作为平台事实，只作参照区间。可以观察分发在哪个区间停住，但原因必须结合实际留存、互动、受众和来源数据判断，不能仅凭播放量反推算法阶段。

### 互动权重复核（2026版，来自 流量机制学习摘要（原始笔记不随仓库分发；平台事实使用前须查当前官方来源））
分析互动数据时按当前权重排序解读，不再默认点赞最重要：抖音收藏率>复访率>铁粉深度互动率>停留时长（点赞几乎不算）；小红书关注×8>转发×4=评论×4>点赞×1=收藏×1或2（收藏权重多份资料有分歧，方向可信数字不强记）。发布后0-0.5h互动权重×1.5、0.5-4h×1、4-24h×0.7、24h后×0.3，复盘早期互动异常高/低时要对照这个衰减窗口再下结论。断更惩罚：抖音7天明显下滑/30天基本清零，小红书7天权重衰减15-30%/15天判定低活跃——账号整体复盘检查发布节奏时可引用此阈值，仍需结合本账号实际数据验证，不能只套用资料数字。

### 四大条件检查
1. 是否按当前可持续产能稳定发布？具体频率由本账号验证，不写死 3-7 条/周。
2. 每条有改进假设？
3. 本期目标是曝光、关注、点击还是成交，指标是否对齐？
4. 发布节奏是否可持续，是否因产能变化引入混杂变量？

## 批量复盘的倍数分级反馈（资料主张，2026-07-21 WIKI补充）

一次性批量产出、批量复盘多条视频时，可以用相对同批平均值的倍数做量化分级，避免逐条主观争论：低于同批平均值5倍以下的，回到选题或钩子重新设计；处于5-10倍区间的，保留但做微调；超过10倍的，视为验证过的支柱内容，原封不动复制其选题/钩子/结构进入下一批。这套分级只用于同一批次内部横向比较，不跨批次、跨账号直接套用绝对倍数。

### 账号所处阶段：实验室 vs 工厂（2026-08补充）

在找到第一个10倍离群值之前，账号处于"实验室阶段"：追求及格线以上质量、批处理多条为一组高频迭代，数据说哪个好就做哪个，不带个人感情judged每一条。一旦某个模板（选题类型/钩子结构/形式）被验证为10倍支柱，账号进入"工厂阶段"：拥有几个验证过的模板并循环使用，直到某个模板数据下滑才重新开启实验室寻找替代品。

复盘时先判断账号当前处于哪个阶段，再决定反馈动作的性质：实验室阶段的反馈是"淘汰/保留/复制"三档判断（上面的倍数分级）；工厂阶段的反馈是"这个验证过的模板还能不能打，什么时候该换"——不要在工厂阶段还对着已验证模板做实验室式的逐条对比，也不要在实验室阶段过早把某条视为"支柱"就不再测试新方向。

判断账号进入工厂阶段时，除了选题/钩子/结构模板，同时检查视觉层面（旋钮、色板、字体、封面风格）是否也出现了连续验证的结果——如果有，提醒老板是否要固化进 `accounts/<账号>/style-bible.md`（见工作台管家 SKILL.md「美学圣经」一节）；老板确认后交工作台管家写入，复盘员和老板都不替对方直接下审美判断。

## 抖音完播率曲线诊断（2026-08补充，抖音账号数据采集用）

数据采集阶段除了 T+1/T+3/T+7 表格数字，还要进创作者服务中心看曲线本身：

**位置**：创作者服务中心 → 数据分析 → 作品数据 → 点开具体作品，能看到双线对比曲线——蓝色是自己视频，黄色是同时长的热门视频基准线，两条线对比能直接看出哪个时间点掉得比同赛道基准快。

**5秒完播率是第一道关卡**：低于25%判定不合格，说明开头/钩子需要换，不必等完整曲线分析完才动手改。

**点赞分析找前置机会**：点赞分析能看到24小时内每一秒的点赞高峰出现在哪，如果高峰点内容出现得偏晚，说明可以把这段内容往前挪，直接提升5秒留人能力——这是比"重新想一个新钩子"更低成本的优化动作，先检查能不能靠挪内容顺序解决，再考虑换钩子。

**诊断优先级**：蓝黄曲线在前5秒就明显分叉 → 优先回编剧/导演改钩子和开头；曲线中段大幅偏离基准 → 检查对应时间点的内容密度和节奏（`剪辑手艺.领域.md`节奏理论）；曲线全程平缓贴近或超过基准但播放量仍低 → 问题不在内容本身，回"分发停点观察"排查标签/账号权重/发布节奏。

## 评论区：账号早期不建流程，账号起量后再启用（2026-08补充）

评论量少的阶段（起号早期）不必建立评论回复的强制工作流，避免为了走流程而勉强凑动作。但复盘时仍要看评论内容本身（层二"内容层"里已有这一项），只是不要求复盘员或老板按固定节奏批量回复。

评论量明显起来后（同批视频评论数持续过前几十条），可以启用轻量提醒：发布后头1小时内的评论优先看和回，比几天后再回效果更好；深度评论（15字以上）本身已经是抖音2026新规里的高权重信号（见`提案师/策略方法.领域.md`），复盘时可以把"评论区是否出现深度评论"作为内容层判断依据之一，不必等专门建了评论运营岗位才开始留意这一项。

## 没流量自查清单（资料主张）

单条视频播放异常低时，先按四类根因排查，再决定优化动作：
1. 标签太泛（没有精准圈定目标人群）
2. 内容质量不达标（对照CQS/CQS相关维度：原创合规、干货价值、结构、视觉）
3. 账号权重低（近期垂直度、违规记录、历史质量）
4. 冷启动数据差（开头流失、完播、初期互动不达标）

四类根因排查完，再给出针对性的五步优化动作（缩小标签、补强开头、调整关键词布局、提升互动引导、观察下一条是否需要调整发布节奏），而不是笼统建议"再拍好一点"。可以作为"分发停点观察"下诊断低播放视频的具体清单使用。

## 内容栈三层复盘

不只是看媒体层表现（播放/点赞），更关注：
- 这条视频有私域转化吗？
- 评论区有人问"怎么买"吗？
- 如果只有播放量没有转化倾向 → 提醒提案师调整策略
