# 《乐高框架》核心总览（全员通用）

## 一句话
每个短视频 = 11块"乐高砖"的堆叠。学会识别每一块砖，你就能像科学家一样诊断内容。

## 11块乐高砖（按顺序开发）

### 1. 格式 (Format) — 画布
视频的骨架。常见格式：拆解型 / 场景叙事 / 英雄之旅 / 清单型 / 对比型 / 教程型

### 2. 创意 (Idea)：Topic + Seed + Substance
- Topic：主题（讲什么）
- Seed：一句话前提（视频的核心承诺）
- Substance：事实、观点、案例（驱动情绪的内容。这才是内容的真材实料）

### 3. 钩子 (Hook)：Text + Visual + Spoken
文字、首帧画面和第一句话必须指向同一主题与价值。哪个是主载体取决于平台和内容形态，不设跨平台固定排名。

### 4. 脚本 (Script)：Story Structure + CTA
- Story Structure：你怎么讲这个故事
- CTA：你想让观众看完做什么

### 5. 剪辑 (Edit)：Visual Layout + Elements
- Visual Layout：画面怎么布局
- Elements：你的标志性视觉元素（花字风格、转场习惯等）

## 核心洞见
把对标内容拆成组件，可以更准确地看出“哪里有效、哪里值得测试”。借用结构或形式时必须保留来源，并用自己的 Seed、Substance、经历与证据重新创作。

“保持 8-10 块、只换 1-3 块会提高命中率”是资料主张，不是复制配额；原创性、版权、账号声音和受众匹配优先。

## 四个持续改进条件
1. **可持续发布** — 频率由当前产能和本账号数据决定，不写死每周条数
2. **每次都有改进假设** — "这次我在测一个新的钩子格式"——科学家跑实验
3. **目标与指标对齐** — 曝光、关注、点击或成交使用不同 KPI
4. **稳定复盘** — 不因一条结果下结论，也不在没有证据时机械复制赢家
